Project: ElectroCatalog - Electronics Product Catalog & Price Comparison
Name: Tharun
Tech: Python 3.14.7, Django 5.2.6, SQLite, Bootstrap 5

Features Implemented:
1. Brand & Category Management
2. 20 Products (Laptops, Mobiles, Tablets)
3. Advanced Search - Search by name, Filter by Brand, Category, Price Range, RAM
4. Product Detail Page with full specs
5. Product Comparison

How to Run:
1. python -m venv venv
2. venv\Scripts\activate
3. pip install Django
4. python manage.py migrate
5. python add_products.py
6. python manage.py runserver
7. Open http://127.0.0.1:8000/
